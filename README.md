# Data Analytics Portfolio

Welcome to my Data Analytics Portfolio! This repository showcases projects demonstrating my skills in data cleaning, data analysis, dashboard development, reporting and data visualisation.

## Projects

### 1. Mobile Sales Analysis Dashboard
**Tools:** Power BI

An interactive dashboard project focused on analysing Mobile sales data and presenting key business insights through visualisations and performance metrics.

### 2. Hospital Emergency Dashboard
**Tools:** Microsoft Excel

An interactive dashboard presenting hospital emergency department information, including patient statistics, waiting times, satisfaction levels, admission status and department referrals.

### 3. Call Center Performance Dashboard
**Tools:** Microsoft Excel

A dashboard analysing call center performance using key metrics such as total working hours and total attended calls.

### 4. E-Pharmacy Data Quality, Pricing & Analytics
**Tools:** MySQL 8.0, Tableau

A data analytics project focused on medicine data quality, data standardisation, cross-source matching, pricing comparisons and anomaly identification. Includes SQL-based data processing and Tableau dashboards.
