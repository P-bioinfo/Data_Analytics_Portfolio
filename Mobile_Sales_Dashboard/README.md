# Samsung Sales Analysis Dashboard

## Project Overview

This project focuses on analysing Mobile sales data using Microsoft Power BI. The objective is to transform sales data into meaningful business insights through an interactive dashboard.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualisation

## Key Performance Indicators (KPIs)
- Total Sales
- Total Transactions
- Total Quantity Sold
- Average Customer Rating

## Dashboard Analysis

The dashboard provides insights into:
- Sales performance across different cities
- Product-wise sales analysis
- Payment method analysis
- Overall sales performance through key metrics

## Project Objective

To develop an interactive sales dashboard that helps users understand sales performance, explore business trends and make data-driven decisions.

## Skills Demonstrated
- Data Analysis
- Data Visualisation
- Dashboard Development
- Power BI Reporting
- Business Insights
