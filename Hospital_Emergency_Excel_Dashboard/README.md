# Hospital Emergency Dashboard

## Project Overview

This project uses Microsoft Excel to analyse hospital emergency department data and present important operational insights through an interactive dashboard.

## Tool Used
- Microsoft Excel

## Key Metrics
- Total Patients
- Average Waiting Time
- Patient Satisfaction
- Admission Status
- Department Referrals

## Dashboard Analysis

The dashboard helps explore:
- Emergency patient statistics
- Patient waiting times
- Patient satisfaction levels
- Admission status
- Department-wise referrals

## Project Objective

To organise and visualise hospital emergency data in a clear dashboard format, helping users understand patient flow and key emergency department performance indicators.

- Microsoft Excel
- Data Analysis
- Dashboard Development
- Data Visualisation
- Operational Reporting
