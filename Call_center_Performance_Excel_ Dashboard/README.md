# Call Center Performance Dashboard

## Project Overview

This project uses Microsoft Excel to present key call center performance metrics through a dashboard.

## Tool Used
- Microsoft Excel

## Key Performance Indicators (KPIs)
- Total Working Hours
- Total Attended Calls

## Dashboard Objective

To provide a simple overview of call center activity by tracking working hours and attended calls.

- Microsoft Excel
- Data Analysis
- Dashboard Development
- Data Visualisation
- Performance Reporting
